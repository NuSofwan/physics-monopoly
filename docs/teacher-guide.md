# คู่มือครู

เปิด `/teacher` แล้วเข้าสู่ระบบ ครู A/B ใช้ได้เฉพาะการทดสอบในเครื่อง ไม่ใช่บัญชีโรงเรียนจริง

1. สร้างชั้นเรียน ม.2/ม.4/ม.5 ระบุหลักสูตร ภาคเรียน หัวข้อ และทักษะที่จะฝึก
2. สร้างชุดโจทย์ให้ตรงระดับชั้น หรือใช้ชุดตัวอย่างของโครงการ (ยังต้องตรวจทาน ไม่ใช่ข้อสอบมาตรฐาน)
3. อัปโหลด PDF ไม่เกิน 20 MB / 80 หน้า รอ worker แยกข้อความหรือ OCR ภาษาไทย หากงานค้าง/ล้มเหลวสามารถยกเลิกและลองใหม่ได้
4. เทียบข้อความกับภาพต้นฉบับ แก้สูตร หน่วย ตัวเลือก เฉลย วิธีคิด คำใบ้ และทักษะ หากแบ่งข้อผิดให้แยก/รวมแล้วแก้เนื้อหาของฉบับร่างใหม่
5. รูปประกอบ: เลือกหน้าต้นฉบับ กำหนดบริเวณ crop ใส่คำบรรยาย และยืนยันว่าไม่ติดเฉลย ระบบไม่ทำการยืนยันนี้แทนครู
6. กดอนุมัติทีละข้อ เมื่อมีอย่างน้อย 10 ข้อจึงเผยแพร่เป็นรุ่น immutable ได้ การแก้ภายหลังไม่เปลี่ยนกิจกรรมเก่า
7. สร้างกิจกรรมจากรุ่นที่อนุมัติ เลือกชั้นเรียน เวลา 15/20/30/40 นาที เมืองที่อนุญาต และเวลาอ่าน/ตอบเสริม 1/1.5/2 เท่า
8. คัดลอกลิงก์หรือแสดง QR ให้เด็ก เปิดบนเครื่องอื่นได้เมื่อ URL เป็น LAN/HTTPS ที่เครื่องนั้นเข้าถึงได้ `localhost` ใช้ข้ามเครื่องไม่ได้
9. หน้า “ห้องและรายงาน” ดูห้อง หยุด/เล่นต่อ/ยุติได้ การยุติระหว่างโจทย์บันทึก interrupted ไม่ใช่ตอบผิด
10. อ่านรายงานพร้อมตัวหาร แยกข้อใหม่/ข้อซ้ำ/ไม่ได้ทำ/ยุติ และส่งออก CSV อย่าจัดอันดับข้ามห้องด้วย XP หรือใช้เป็นคะแนนสอบโดยอัตโนมัติ

ชื่อเล่นไม่ใช่ทะเบียนนักเรียน ยังไม่มีการผูก student ID อย่างเป็นทางการ อย่าให้เด็กใช้ชื่อเต็มหรือข้อมูลติดต่อ
การเก็บข้อมูลเริ่มต้น 180 วันเป็นนโยบายผลิตภัณฑ์ ไม่ใช่ข้อกำหนดกฎหมาย หน้าอายุข้อมูลแสดงวันที่ควรทบทวนและลบแบบยืนยันเอง
การลบกิจกรรมไม่ลบคลังโจทย์ที่อาจใช้ร่วมกัน ต้องลบชุดโจทย์แยกเมื่อไม่เหลือกิจกรรมอ้างอิง ไฟล์ลบผ่าน worker จึงต้องเปิด worker ให้ทำงาน
สำเนาสำรองต้องมีผู้ดูแลจัดการอายุ/สิทธิ์และป้องกันการนำข้อมูลที่ลบแล้วกลับเข้าระบบโดยไม่ตรวจทาน
