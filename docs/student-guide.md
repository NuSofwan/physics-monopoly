# คู่มือนักเรียน

เปิดลิงก์กิจกรรมของครู ใส่ชื่อเล่น 2–20 ตัวอักษรที่ไม่ซ้ำในห้อง เลือกหนึ่งใน 24 ตัวละครและปรับรูปลักษณ์ก่อนเข้าห้อง ทุกอาชีพใช้กติกาเดียวกัน

- คนแรกกดสร้างห้อง เลือกเมืองที่ครูอนุญาต แล้วส่งรหัสห้อง 6 ตัวให้เพื่อน
- เพื่อนเปิดลิงก์กิจกรรมเดียวกัน ใส่รหัสห้องและกดเข้าห้อง เล่นได้ 1–4 คน
- ทุกคนกดพร้อม เจ้าของห้องเริ่มเกมได้ การเปลี่ยนเมืองยกเลิกสถานะพร้อม ให้ทุกคนตรวจและกดพร้อมใหม่
- ถึงตาของคุณ ทอยลูกเต๋าและเลือกซื้อ/อัปเกรด/ผ่าน ทุกคนได้ตอบโจทย์พร้อมกัน ไม่ว่าคนเดินจะซื้อหรือผ่าน
- ขอคำใบ้ก่อนตอบได้ หากตอบผิดจะมีช่วงลองใหม่หลังทุกคนตอบครั้งแรก เฉลยเปิดเมื่อปิดรอบตอบแล้ว
- เงินหมดไม่ทำให้ถูกไล่ออกจากห้อง ระบบช่วยเหลือและหนี้แสดงในผลเกม
- เกมจบตามเวลาที่ครูตั้งไว้ มีรางวัลเมืองและการเรียนรู้แยกกัน ไม่รวมเงินกับ XP เป็นคะแนนเดียว
- หลังเกมดูผลส่วนตัวตามทักษะ และเปิดข้อที่ได้ทำแล้วเพื่อทบทวนวิธีคิด การทบทวนไม่เพิ่มคะแนนย้อนหลัง

หากภาพช้า เลือกกระดาน “ข้อความ (ประหยัดเครื่อง)” ลดการเคลื่อนไหว หรือปิดเสียงได้ กระดานสำรองยังใช้ข้อมูลจาก server เดียวกับเพื่อน ปรับขนาดตัวอักษรได้ 100/125/150% กล้อง 3 มิติมีตัวเลือกติดตามผู้เล่นและรีเซ็ตมุมมอง หาก WebGL หยุดทำงาน ระบบสลับไปกระดานข้อความโดยไม่ต้องเปลี่ยนห้อง
หากเน็ตหลุด รอระบบเชื่อมต่อใหม่ หรือเปิดลิงก์เดิมในแท็บ/อุปกรณ์เดิมและกดกลับเข้าเกมเดิม อย่าล้าง session ของเบราว์เซอร์
ชื่อเล่นอย่างเดียวใช้แอบอ้างคนเดิมไม่ได้ หาก session สูญหายให้แจ้งครู ไม่ส่ง reconnect token ให้ผู้อื่น
